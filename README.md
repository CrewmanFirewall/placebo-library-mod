# Placebo — Shared Library Mod

[![Download Latest](https://img.shields.io/github/v/release/CrewmanFirewall/placebo-library-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/CrewmanFirewall/placebo-library-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A lightweight shared library used by Shadows_of_Fire mods including Apotheosis and Hostile Worlds.

![Placebo — Shared Library Mod Preview](https://cdn.modrinth.com/data/tCkE8p2N/f5a71de378c2cc940efaa812da151c480cfdbbb6_96.webp)

## Features

- Required by Apotheosis, Loot Beams, and other mods
- Shared loot system hooks for modifying vanilla loot
- FastUtil integration for high-performance collections
- Registry utilities for mod-safe block and item creation
- Minimal footprint — essentially zero gameplay impact

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
